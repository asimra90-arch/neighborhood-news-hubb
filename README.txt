Neighborhood News Hub project

Files:
- index.html: news website homepage/hub
- Community_Park_News_Story.html: article page with a link back to the homepage
- documents/Community_Park_News_Story.pdf: PDF version of the article

To use:
1. Keep the folder structure intact so the links work.
2. Open index.html in a browser to preview the site.
3. Upload the files and documents folder to your GitHub repository.
4. Enable GitHub Pages in the repository settings if required by your class.
5. Replace the example external news link with a source that best fits your area if your teacher expects a specific local outlet.
